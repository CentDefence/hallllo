# Misterio Design — Telegram-бот (версия для Vercel)

Эта версия бота работает через **webhook**, а не через постоянно запущенный
процесс (polling). Это значит: Telegram сам присылает каждое новое сообщение
на твой URL на Vercel, а Vercel обрабатывает его и "засыпает" — платить за
постоянно висящий сервер не нужно, бесплатного тарифа Vercel достаточно.

## Важное отличие от предыдущей версии
Serverless-функции не хранят данные между вызовами (каждый запрос — как
новый запуск программы с нуля). Поэтому:
- **Язык** передаётся прямо внутри самих кнопок (в `callback_data`), а не
  хранится в памяти бота — переключение языка работает всегда, при любом
  количестве пользователей и перезапусков функции.
- **Корзина** (добавление нескольких услуг в список) убрана — вместо неё
  у каждой услуги в каталоге сразу кнопка «Заказать эту услугу», которая
  открывает Telegram-чат с тобой. Если очень нужна многотоварная корзина —
  для этого потребуется подключить внешнюю базу данных (например, Vercel KV
  или Supabase), могу дописать отдельно.
- Команды, набранные вручную (`/menu`, `/catalog` и т.д., без прохода через
  кнопки) по умолчанию открываются на русском — у языка нет памяти между
  сообщениями. Переключить можно кнопкой 🇬🇧/🇷🇺 в меню.

## Структура проекта
```
misterio_bot_vercel/
├── api/
│   └── webhook.py     ← точка входа для Vercel (serverless-функция)
├── bot_core.py         ← вся логика бота (общая для локали и продакшена)
├── texts.py            ← все тексты RU/EN, ссылки, услуги
├── keyboards.py        ← инлайн-клавиатуры
├── bot.py              ← локальный запуск через polling (только для теста)
├── set_webhook.py       ← скрипт, который "включает" webhook после деплоя
├── vercel.json          ← настройка маршрутов для Vercel
├── requirements.txt
└── .env.example
```

## Шаг 1. Получи токен бота
В Telegram: [@BotFather](https://t.me/BotFather) → `/newbot` → следуй инструкциям.
Сохрани токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

## Шаг 2. Задеплой на Vercel
1. Установи Vercel CLI (если ещё нет):
   ```
   npm install -g vercel
   ```
2. Зайди в папку проекта и запусти:
   ```
   vercel login
   vercel
   ```
   Отвечай на вопросы по умолчанию (Enter) — Vercel создаст проект.
3. Добавь переменную окружения с токеном:
   ```
   vercel env add BOT_TOKEN
   ```
   Вставь свой токен, когда попросит. Выбери все окружения (Production,
   Preview, Development).
4. Задеплой в продакшен:
   ```
   vercel --prod
   ```
   В конце Vercel покажет ссылку вида `https://misterio-bot.vercel.app`.

## Шаг 3. Скажи Telegram, куда слать обновления
Локально (на своём компьютере), там где лежит `set_webhook.py`:
```
pip install -r requirements.txt
cp .env.example .env      # и впиши туда BOT_TOKEN
python set_webhook.py https://misterio-bot.vercel.app
```
Скрипт должен вывести "✅ Webhook установлен".

## Шаг 4. Проверь
Напиши боту `/start` в Telegram — должно появиться меню выбора языка.
Готово — бот работает 24/7, ничего не нужно держать запущенным.

## Если что-то не отвечает
- Открой `https://твой-проект.vercel.app/api/webhook` в браузере — должен
  показаться `{"status": "Misterio Design bot is running"}`. Если ошибка —
  смотри логи: `vercel logs` или в дашборде Vercel → вкладка Logs.
- Проверь, что переменная `BOT_TOKEN` действительно добавлена в Vercel
  (Project Settings → Environment Variables).
- После каждого нового деплоя (`vercel --prod`) webhook перезапускать не
  нужно — URL остаётся тем же, если ты не менял имя проекта.

## Локальный тест перед деплоем (необязательно)
Если хочешь проверить тексты/кнопки на своём компьютере до деплоя:
```
pip install -r requirements.txt
cp .env.example .env      # впиши BOT_TOKEN
python bot.py
```
Это включит старый режим polling — удобно для отладки, но для постоянной
работы используй Vercel + webhook, как описано выше.
